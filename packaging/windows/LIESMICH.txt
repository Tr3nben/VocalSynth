VocalSynth – Installation unter Windows
=======================================

Inhalt dieses Pakets
--------------------
  Install-VocalSynth.bat     installiert alles mit einem Doppelklick
  Uninstall-VocalSynth.bat   entfernt alles wieder
  VST3\                      VocalSynth FX.vst3, VocalSynth Instrument.vst3
  CLAP\                      VocalSynth FX.clap, VocalSynth Instrument.clap
  Standalone\                VocalSynth FX.exe (zum Testen ohne DAW)

Installation
------------
1. ZIP-Datei komplett entpacken (Rechtsklick > "Alle extrahieren").
2. Im entpackten Ordner "Install-VocalSynth.bat" doppelklicken und die
   Administrator-Abfrage bestätigen.
   - Mit Enter wird in den Standard-Ordner installiert:
       C:\Program Files\Common Files\VST3\VocalSynth\
       C:\Program Files\Common Files\CLAP\VocalSynth\
   - Nutzt FL Studio bei dir einen eigenen VST3-Ordner, gib ihn an; dann
     landet alles in <dein Ordner>\VocalSynth\.
   - Falls Windows "Der Computer wurde durch Windows geschützt" meldet:
     "Weitere Informationen" > "Trotzdem ausführen". Die Dateien sind noch
     nicht signiert.
3. FL Studio öffnen: Options > Manage plugins > "Find installed plugins".
   FL Studio durchsucht auch Unterordner, der Ordner "VocalSynth" wird also
   gefunden.

Was ist das für eine Version? (0.1.0, Meilenstein 1)
----------------------------------------------------
Das ist ein TESTBUILD für den FL-Studio-Routing-Test. Er analysiert deine
Stimme noch nicht. Stattdessen erzeugt das Plugin selbst festes Test-MIDI,
damit wir herausfinden, auf welchem Weg MIDI in FL Studio 2026 bei einem
Synth ankommt (Tests T1 bis T7).

Die Schritt-für-Schritt-Anleitung mit allen Klickwegen und einer Tabelle
zum Ausfüllen liegt als FL-ROUTING.md in diesem ZIP (mit dem Editor
öffnen) und steht auch auf GitHub:
  https://github.com/Tr3nben/VocalSynth/blob/master/docs/FL-ROUTING.md

Der Testmodus im Plugin (beide Varianten, englisch beschriftet):
  Test Pattern       Off / Notes (Tonleiter) / Pitch Bend (Sweep) /
                     CC Sweep / All (alles im Wechsel). Standard: Off.
  MIDI Channel       MIDI-Kanal 1-16 für das Test-MIDI.
  Test tempo (BPM)   Tempo des Testmusters (60-200 BPM, Standard 120).
                     Läuft unabhängig vom FL-Tempo und ohne Play-Taste.
  CC Number          Controller für den CC Sweep (Standard 1 = Mod-Rad).
  Monitor Tone       Sinuston im Plugin spielt das Muster hörbar ab,
                     ganz ohne MIDI-Routing (Test T6).
  Virtual MIDI Out   Virtueller MIDI-Port "VocalSynth FX" bzw.
                     "VocalSynth Instrument" für Windows (Test T7).
                     Braucht Windows 11 mit Windows MIDI Services.
                     Status im Plugin: off / open / failed.
  Restart pattern    Muster neu starten, nach jeder Routing-Änderung.
  Drag test MIDI/WAV Test-Clip (.mid bzw. .wav) mit der Maus nach FL
                     ziehen.
Außerdem zeigt das Plugin Eingangspegel, Zähler der gesendeten MIDI-
Nachrichten, Samplerate und die Blockgrößen, die FL schickt.

Ausprobieren
------------
- VocalSynth FX: im Mixer auf den Insert legen, auf dem dein Mikrofon liegt.
  Der Pegelbalken im Plugin zeigt, ob deine Stimme ankommt.
- VocalSynth Instrument: im Channel Rack als Instrument laden.
- Schnelltest ohne Routing: "Test Pattern" auf "Notes" und "Monitor Tone"
  einschalten. Du hörst eine Sinus-Tonleiter direkt aus dem Plugin.
- Für alles Weitere: Anleitung FL-ROUTING.md (liegt im ZIP).

Tipp: Fang leise an, der Pitch-Bend-Sweep ist auf Dauer anstrengend.

Ohne Installationsskript
------------------------
Die beiden .vst3-Ordner aus "VST3\" einfach in einen Unterordner
"VocalSynth" deines VST3-Ordners kopieren, z. B.
  C:\Program Files\Common Files\VST3\VocalSynth\
